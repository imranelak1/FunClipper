# Desktop and web clip utility

Mode: Operate. The user starts capture, saves a recent clip, trims/mutes it, and shares. Desktop metrics must state actual availability. Web works as a local preview until hosted.

## Direction contract

THESIS: Put the latest clip and its actions ahead of library navigation. Compact controls replace a social-feed layout.

OWN-WORLD: Requested reference update: charcoal surfaces, pale violet actions, clear neutral strokes, real media, and a translucent corner recording widget. Bahnschrift and tabular readings; native dark chrome. Vengeance dock grouping, Skiper compact expansion, and Animmaster interaction transitions are adapted without a browser runtime.

STORY: See capture status, choose a quality profile, start intentionally, save without losing game focus, then edit or share.

FIRST VIEWPORT: Main header, capture/profile controls, real vitals and recent clips. A separate small semi-transparent topmost corner widget shows record state, elapsed time, CPU/GPU/RAM, replay readiness and direct controls. The editor remains media-led; the companion web uses matching dark rows and a responsive player.

FORM: Compact utility; directly specified task flow, no concept seed needed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
